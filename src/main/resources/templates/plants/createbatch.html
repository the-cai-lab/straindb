About the template:

  1. Do not change the header (first line) of the template. Also, do not change the order of the columns, add new columns, or remove columns.
  2. The columns "genotype" and "species" are mandatory and cannot be left blank, as indicated by the "*".
  3. Valid values for "species" are one of "thale cress", "potato", or "sweet potato" (case-insensitive). Contact the system administrator if you want other species to be added to this list. (Hint: Purposely submit a record with an incorrect value to see the options available to you in the error message.)
  4. Other than the aforementioned "species", all other fields are free-form text strings. Tab characters will be replaced with spaces. Please avoid using tabs in your input.
  5. If you plan to edit the template using Microsoft Excel and you have used non-English characters (i.e., Greek characters, etc.), then you must save as the "CSV UTF-8" format. Do not select "CSV" (with "UTF-8" omitted).

If you have problems having an upload being validated, then feel free to let the system administrator know.
